🔴 Rover-K — Mars Rover

Program a Mars rover in Forth. Every action pauses so the animation can finish before the Task resumes.

▲
How to play

Goal: collect every crystal ◆, return to base ⌂, then transmit. Quicksand ≈, craters ●, or running out of power will end the mission.

forward moves ahead, left/right turn, drill collects a crystal, and scan leaves 1 on the stack when danger is ahead, otherwise 0.

Define new words with : name … ;, repeat with 3 for … next, branch with … if … else … then, and start comments with \ . These control words are grown by the game from the Project-K API; they are not kernel primitives. Fewer Forth words means a better score.

Forth was originally created for controlling astronomical equipment—a fitting ancestor for a tiny programmable rover.
